# Verification record — Murmur 0.1.0

Tested 2026-11-04/05 on Windows 11 Home build 26200, Snapdragon X X1-26-100 (8 logical processors), 16 GB RAM. ARM64 is physical/native. x64 execution is Windows emulation on the same ARM machine; it is not a physical Intel/AMD performance measurement.

## Executed checks

- **48/48 core tests passed.** Protected amounts, URLs/code/email tokens, self-corrections, English time formatting, short-reply bypass, email paragraphs, dictionary/snippet literal handling, recording states, double-Ctrl/single-Ctrl semantics, shared deletion/conflicts/unsharing/privacy, atomic SQLite rollback and backup, signed-update tamper/architecture rejection, and verified-quote answer grounding. Deliberately mutating overlay visibility to include idle made the relevant test fail; original source was restored.
- **14/14 service integration checks passed.** Windows DPAPI encrypted storage, provider event parsing/timezones/unsafe links, reminders once per event, and the actual child-process MCP stdio protocol including privacy, pagination and rejection of writes. A local HTTP fixture also verified partial-range resume, invalid-hash rejection without replacing the installed model, cancellation and resumable partial retention.
- **36 owned-field insertion checks passed earlier:** 18 in native TextBox/RichTextBox and 18 in WebView2 textarea/contenteditable. Unicode/multiline, selection replacement, no Enter submission, caret/value/field changes, cancellation, original clipboard restoration and a closed target. The first unguarded attempt mistakenly placed fixture text in a ChatGPT draft (not sent); that evidence was discarded and the harness now requires the foreground PID to be its own fixture before every paste. Later browser failures were traced to fixture pipe encoding and rerun successfully with UTF-8.
- Additional concurrent-clipboard and overlay nonactivation checks were added, but their rerun refused all input because the foreground desktop was LockApp. They are **not marked passed**. Electron, elevated targets, IME, physical x64, multiple monitors, physical unplug and sleep/resume remain unverified conditions.
- Real microphone setup test ran for five seconds earlier, with test audio deleted. This establishes device access, not recognition quality or unplug resilience. A later no-packet check improves error reporting; silence is distinguished from no packets.
- Actual UI/CDP checks: onboarding, reference-sized home/settings, model selection, dictionary/snippet persistence, new note/edit title, separate private notes and generated summary, immediate-close saving, hidden hub teardown and successful reopening. The summary was generated by the real local model from the clearly identified synthetic meeting below. No mock transcript is used in production.
- Native PE inventory: **505 ARM64 and 523 x64 PE files**, no wrong-architecture native files; neutral managed assemblies allowed. The native speech, VAD, writing and optional speaker paths executed on ARM64 and on emulated x64.

Raw JSON/log evidence is in artifacts/ in the working project and the delivered evidence folder. Scripts and fixture definitions are included in source; private reference screenshots are excluded.

Isolated Moonshine CPU benchmark: four threads, approximately 1.49 s model load, 238–266 ms JFK decode, about 366 MB peak process working set. Parakeet research comparison used about 930 MB and ~631–690 ms JFK decode, so the smaller English-only model was selected. Initial Whisper base was ~3.19 s on the same JFK clip. These are different measurement layers; do not add arbitrary earlier values into an end-to-end claim.

Final x64 package executed the same speech and cleanup path successfully under ARM emulation, plus two-voice diarization. The package validation ran during installer compression: its 4.2 s recognition and 6.7 s cleanup are **contended compatibility checks**, not Intel/AMD speed claims. No measured comparison with Wispr cloud latency is available.

Preparation during pauses can reduce post-stop cleanup, but final full-audio recognition must match exactly before reusing prepared text. This optimization is implemented and reviewed; user-microphone stop-to-insert latency has not been fully timed. Cold starts and longer meetings take longer. Meetings are transcribed after stopping, not incrementally streamed. Continuous speech without a usable pause still meets the bounded processing-window boundary; arbitrary long speech quality needs more testing.

## Installation and remaining release limits

Fresh automatic setup completed with exit code 0 on this PC; the installed executable is AA64, with Start-menu and Installed Apps entries, the guide, native engines and licenses. Silent uninstall completed with exit code 0, removed the program and retained the database and models. Final reinstall and same-version upgrade also completed with exit code 0, preserving every database row and the downloaded models. The installed executable matches the final ARM64 publish byte-for-byte. The release SHA-256 inventory accompanies the delivered packages. Interactive permanent-data deletion is guarded against reparse-point traversal but was not exercised against real user data.

Local core use is available without subscriptions. Google/Microsoft calendar registrations and live account consent, hosted shared identities/invitations, public HTTPS release hosting and Windows signing credentials are not provided. Shared libraries use external storage permissions. The update manifest verification is tested; public delivery and automatic binary rollback after a partly failed installer are not production-verified.

Known functional differences: English only, plain-text snippet insertion, keyboard shortcuts rather than mouse shortcuts, no custom per-transform global hotkeys, manual calendar refresh, no proprietary cloud equivalence, and differences in illustration/icons/settings dialogs. The parity checklist distinguishes implementation from test evidence. Summaries use a small local model and require review; the first summary fixture lost a decision, prompting a revised instruction and an explicit regression recheck that retained all expected facts.

The final question check initially exposed an invented room number. Meeting Q&A now returns only model-selected verbatim transcript quotes validated against the cited source. Unsupported quotations, invalid source IDs and malformed output are rejected; queries with no matching content return an explicit no-information result. Four regression checks cover this behavior. This favors faithful excerpts over free-form answers.

Background-start regression: the final process check caught WinForms showing a blank form after a Load-time Hide. Visibility is now suppressed in SetVisibleCore until an explicit Open request. The new background process stayed running with no visible main window and about 69 MiB working set; opening the existing instance was separately checked.
